PALPRINTS UI icons

You can replace these SVG files with your preferred icon pack while keeping the same filenames:
- language.svg
- sun.svg
- moon.svg
- eye.svg
- eye-off.svg
- google-g.svg

Printer service icon slots are wired in styles.css from the services subfolder. Add your own SVGs under assets/icons/services with these filenames:
- tshirt.svg
- hoodie.svg
- mug.svg
- bag.svg
- cap.svg
- notebook.svg
- paper-products.svg
- sticker.svg
- poster.svg

Recommended: one consistent outline icon pack, stroke around 1.5.
